# Aev0rnJP Official Portal

Aev0rnJPの公開プロフィール、YouTubeチャンネル、GitHubプロジェクト、キャラクター資料、関連リンクをまとめる静的ポータルサイトです。

## 公開予定URL

https://mylifereading6666-oss.github.io/Aev0rnJP-Portal/

## 主な機能

- 日本語 / English 切り替え
- スマートフォン・タブレット・PC対応のレスポンシブレイアウト
- プロジェクト一覧、カテゴリフィルター、キーワード検索
- YouTube・GitHub・公開Webアプリへのリンク
- キャラクター資料の画像表示・拡大表示
- ダークテーマ、ブルー・パープルのネオンデザイン
- HTML / CSS / JavaScriptのみで動作する静的構成

## キャラクター画像の配置

assets フォルダーに次の画像を配置してください。

- assets/character-pencil.webp — 色鉛筆で描いた三面図
- assets/character-3d.webp — 3Dキャラクターの三面図

画像が配置されると、キャラクター紹介欄に自動表示されます。画像はタップ / クリックで拡大できます。

## GitHub Pagesで公開する方法

1. GitHubリポジトリの Settings → Pages を開きます。
2. Build and deployment の Source で Deploy from a branch を選びます。
3. Branch を main、Folder を /(root) に設定して保存します。
4. デプロイ完了後、公開URLを開きます。

## 技術構成

- HTML / CSS / Vanilla JavaScript
- GitHub Pages
- バックエンド・データベース・ビルド工程なし
